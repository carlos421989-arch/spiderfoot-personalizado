# SpiderFoot - compilacao unificada de codigo (2026-10-20)

Contem a base original recuperada (com AI Summary / Ollama / OpenRouter),
mais as atualizacoes incrementais da Minha Exposicao Digital ate verificacao publica.

**O modulo Minha Exposicao Digital continua presente**, mas seus resultados permanecem limitados:
nao encontrou exposicao confirmada nas buscas experimentais.

**IMPORTANTE:** este pacote contem codigo e testes, **NAO** inclui bancos de dados,
varreduras antigas, senhas, chaves API, arquivos .env, venv ou backups.
Nao apague as instalacoes antigas antes de migrar/conferir os bancos e validar
a aplicacao na sua maquina. Não mistura automaticamente SQLite de diferentes instancias.

Instalacao segura: extraia para uma nova pasta, instale dependencias Python no
ambiente apropriado, use diretorio de dados novo e teste o AI Summary.

Caso queria somente o SpiderFoot com IA, deixe a rota Minha Exposicao sem uso.

Nao execute exclusao de pastas antigas ate criar e verificar backups de todas.
